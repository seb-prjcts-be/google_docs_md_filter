Docs without .md

Markdown and Word files leave the Google Docs home screen. In Drive they stay where they are.

Install → Guide →
docs.google.com/document/ · /picker

Where it runs

A synced folder in Drive puts every .md and .docx on the Docs home screen, next to your documents. When a coding tool writes a few dozen Markdown files a day, the letter you opened yesterday is a long scroll down. The extension hides those rows in the page with display: none. The files are not touched.

  1. 01Home screen

    Grid cards and list rows on docs.google.com/document/. A date section such as Yesterday folds away when everything in it is hidden.

  2. 02Search suggestions

    The autocomplete list under the search bar at the top of the home screen.

  3. 03File > Open

    The picker dialog you open from inside a document. The document itself is left alone.

  4. –Nowhere else

    Open documents, Google Drive, Sheets, Slides, Forms, the attachment picker in Gmail and every other website. The exact addresses are in the Guide.

About

Why

I keep project folders in Google Drive, synced from my computer. The code tools I work with write Markdown all day: notes, plans, status files. Docs shows every one of them on its home screen, newest first, and the letter I opened yesterday ends up below forty README.mds. The folders have to stay where they are; that is the point of syncing them. So the files stay, and the browser stops showing them in the one place where they are in the way.

    I designed and tested it and directed the code, much of which was written with AI help. If something is wrong, open an issue. The animations are drawn by scripts/generate-gifs.js, in the pixel style of my plotter libraries; the Google colours become the nearest CGA colours.
