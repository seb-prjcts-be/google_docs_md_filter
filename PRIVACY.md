# Privacy Policy for MD Block for Google Docs

Last updated: 2026-10-29

MD Block for Google Docs runs entirely inside your browser on `docs.google.com` and the Google Docs file picker (`docs.google.com/picker` and `drive.google.com/picker`).

## Data collection and transmission

- The extension does not collect, log, transmit, or share personal information, document titles, document contents, or browsing history.
- The extension makes no external network requests and contains no analytics, telemetry, or remote code.
- The extension does not modify, move, or delete any files in Google Drive. It only hides matching rows visually in the browser DOM (`display: none`).

## Local settings

Your filter preferences (whether the filter is active, which file extensions are hidden, and whether the bottom-left counter button is visible) are stored locally in your browser using `chrome.storage.local`. Removing the extension deletes those stored preferences.
