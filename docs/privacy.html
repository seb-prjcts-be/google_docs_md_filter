Privacy policy · last updated 2026-10-29

Privacy

MD Block for Google Docs runs entirely in your browser, on docs.google.com and in the Google Docs file picker (docs.google.com/picker and drive.google.com/picker).

Data collection and transmission

  • The extension does not collect, log, transmit or share personal information, document titles, document contents or browsing history.
  • The extension makes no external network requests and contains no analytics, telemetry or remote code.
  • The extension does not modify, move or delete any files in Google Drive. It only hides matching rows in the page (display: none).

Local settings

Your filter preferences (whether the filter is on, which file extensions are hidden, and whether the counter button is shown) are stored in your browser with chrome.storage.local. Removing the extension deletes them.

Permissions

PermissionWhy
storageKeeps the settings above on this computer.
docs.google.comRuns the filter on the Docs home screen and in the File > Open picker. Open documents are excluded.
drive.google.com/pickerRuns the same filter when the picker is served from Drive. The rest of Drive is not included.

Check it yourself

The whole extension is about 1 800 lines of plain JavaScript in src/, with no build step and no dependencies.
