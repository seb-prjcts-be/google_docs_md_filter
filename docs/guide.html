Chrome extension · v0.1.0

Guide

The extension looks at the Docs home screen, finds rows whose file name ends in a filtered extension and hides them in the page. Drive is not asked to do anything.

Where it runs

The addresses come from manifest.json. Anything not on this list is never touched.

AddressWhat
docs.google.com/document/The Docs home screen: grid cards, list rows and the search suggestions at the top.
docs.google.com/u/*The same home screen when you switch between accounts.
docs.google.com/a/*/document/The same home screen under a Workspace domain address.
docs.google.com/pickerThe File > Open dialog, inside its own frame.
drive.google.com/pickerThe same dialog when Google serves it from Drive.

Open documents (/document/d/...) are excluded twice: once in exclude_matches in the manifest and once in detectSurface() in src/filter-core.js. Google Drive itself, Sheets, Slides, Forms and the attachment picker in Gmail keep showing every file, so you can still attach a .md to an email.

How it decides

For every card or row, classifyItemElement() looks for the file name, in this order: the title element, its title or aria-label attribute, tooltips, inline labels, and the row's own aria-label. When the name ends in a filtered extension, the row gets display: none. When no name is found, a Markdown or Word MIME type, icon or badge is enough.

A name only counts when the extension sits directly after a letter or digit. notes.md is hidden; .md on its own and notes .md are not.

A date section such as Yesterday folds away when every item in it is hidden, unless its header holds the sort or view buttons.

Settings

Click the MD Block icon in the toolbar.

SettingDefaultWhat it does
Filter switchonPauses or resumes filtering in every open Docs tab. On a Docs tab the toolbar icon shows how many files are hidden, or OFF while paused.
.md / .markdownonMarkdown files.
.docx / .doconMicrosoft Word, including .docm, .dotx, .dot and .dotm.
.txtoffPlain text.
.json / .jsonloffJSON and log lines.
.yaml / .ymloffYAML config.
.tomloffTOML config.
.logoffLog files.
Extra extensionnoneYour own, such as tex or csv. Letters, digits, hyphen and underscore.
Counter buttononShows or hides the button in the bottom-left corner of the home screen.

Settings are kept in chrome.storage.local, on this computer only. See Privacy.

The counter button

The button counts what is hidden on the screen you are looking at. It says 14 .md hidden when only Markdown is hidden, 3 Word hidden when only Word is, and 17 files hidden for a mix. Click it and the files come back, with the label 17 files shown · hide; click again to hide them. In the File > Open dialog the button stays out of sight until something is hidden.

Languages

The button and the settings follow the browser language. English and Dutch are included in _locales/; other languages fall back to English. A new language is one messages.json file; a pull request is welcome.

Limits

  • The extension hides what Google has already loaded. When many .md files sit at the top of Recent Documents, it nudges the page up to fifteen times so Docs loads older documents into view. If hundreds come before the first native document, scroll once by hand to fetch the next batch.
  • A native Google Doc whose title ends in .md or .docx is hidden too. The title is what the extension reads.
  • Google changes the Docs interface now and then. When it does, the selectors may need an update. The tests in test/filter.test.js cover the structures seen so far.
  • This is a browser-side workaround. It does not switch off the way Drive shows Markdown and Word files in Docs, and it does not change anything in your account.

Test and package

The tests need Node.js and no npm packages.

node --test test/filter.test.js

A clean zip for the Chrome Web Store or a GitHub release, in dist/. It holds manifest.json, _locales/, icons/ and src/, nothing else:

node scripts/pack.js

The icons and the animation on the home page are drawn by scripts as well:

node scripts/generate-icons.js
node scripts/generate-overview-gif.js

The animation uses src/filter-core.js to decide which rows disappear and what the button says; the file names in it are invented.

Tested with the Node v24.16.0 test suite and on the Google Docs home screen in Chrome on Windows on 2026-10-29.
