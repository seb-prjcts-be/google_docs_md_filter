About MD Block

My Google Docs home screen filled up with .md files, and I wanted my documents back without moving a single file.

Why

I keep project folders in Google Drive, synced from my computer. The code tools I work with write Markdown all day: notes, plans, status files. Google Docs shows every one of them on its home screen, newest first, and the letter I opened yesterday ends up below forty README.mds. Word archives in shared folders do the same.

The folders have to stay where they are; that is the point of syncing them. So the files stay, and the browser stops showing them in the one place where they are in the way.

What it is not

It is a workaround in the browser. It does not switch off the way Drive and Docs handle Markdown and Word files, and it cannot. When Google offers a setting for this one day, use that and remove this.

Docs does have an Enable Markdown option under Tools > Preferences. It is about typing: # becomes a heading, ** becomes bold, and you can paste or copy Markdown. It does not change which files the home screen lists, so ticking it or not makes no difference here.

It is an independent extension for the Google Docs web interface, not affiliated with or endorsed by Google LLC.

How this was made

Designed, tested and directed by me; much of the code was written with AI assistance. The responsibility for what it does is mine. If something is wrong, open an issue and I will look at it.

The animations on this site are drawn by scripts/generate-gifs.js, in the same pixel style as the animations of my plotter libraries. They show the Docs home screen with every Google colour replaced by the nearest of the sixteen CGA colours, the way the p5 pink becomes magenta there. Measured as the eye sees colour (CIELAB), the plus keeps its red, yellow, blue and green. The pale greys of the dividers and the search bar are lighter than anything CGA has, so they are dotted in light grey, as 1980s screens did.
