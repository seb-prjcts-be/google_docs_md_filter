Chrome extension · v0.1.0

Install

The extension is not in the Chrome Web Store yet. Until it is, you load it from source. That takes a minute and works in Chrome, Brave, Edge, Arc and Vivaldi.

From a release

  1. Download the latest md-block-v*.zip from Releases and unzip it into a folder you will keep. Chrome reads the extension from that folder every time it starts.

  2. Open chrome://extensions.

  3. Turn on Developer mode in the top-right corner.

  4. Click Load unpacked and choose the folder that holds manifest.json.

  5. Open or reload https://docs.google.com/document/.

If you run Google Docs as an installed app (PWA), the extension works there too.

From a clone

git clone https://github.com/seb-prjcts-be/google_docs_md_filter.git

Then follow steps 2 to 5 above with the cloned folder. The folder also holds this site, the tests and the scripts; Chrome only reads what manifest.json names.

Check that it works

On the Docs home screen a small button appears in the bottom-left corner. It counts what is hidden on the current screen, for example 14 .md hidden, or 0 files hidden when nothing matched. Click it to show the hidden files for a while; click again to hide them.

The MD Block icon in the toolbar opens the settings. Chrome may tuck it under the puzzle piece; pin it there if you want it in sight.

Update

Replace the folder with the new release, or git pull in the clone. Then click the round arrow on the extension's card in chrome://extensions and reload the Docs tab.

Remove

Click Remove on the extension's card in chrome://extensions. Chrome deletes the stored settings with it. Nothing in Drive changes, because nothing in Drive was changed in the first place.

If it does not work

  • No button on the home screen: check that the extension is switched on in chrome://extensions, then reload the Docs tab. The address should start with docs.google.com/document/.
  • No button inside a document: that is on purpose. The extension does not run in the editor. Choose File > Open to see it work in the picker.
  • A native Google Doc is missing: its title probably ends in .md or .docx. The title is what the extension reads. Click the button to show it, or rename it.
  • Older documents do not appear: see Limits.
